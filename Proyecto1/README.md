# QuetzalMart - Implementación de Odoo ERP y Sistemas Integrados

Este repositorio contiene la configuración, documentación y scripts (RPA) para el **Proyecto de Implementación de Sistemas (Segundo Semestre 2026)** de la empresa **QuetzalMart**. 

## Descripción del Proyecto

QuetzalMart es una cadena de tiendas en expansión (con sucursales en Guatemala, México y El Salvador) que requiere modernizar su infraestructura tecnológica. Este proyecto unifica las operaciones de la empresa a través de las siguientes tecnologías:

1. **Odoo ERP (Community en la nube):** Módulos de Ventas, Compras, Empleados y Facturación centralizados en un único sistema.
2. **E-Commerce y CRM:** Portal web conectado directamente al ERP con automatización de marketing y correos electrónicos post-compra.
3. **Google Analytics (GA4):** Modelo de comercio electrónico mejorado para registrar interacciones (visitas, abandonos de carrito y compras).
4. **Sistema de Gestión Documental:** Repositorio para digitalizar contratos y facturas, asegurando el cumplimiento normativo.
5. **UiPath (RPA):** Robot de automatización para la extracción y carga masiva de catálogos de clientes y productos desde hojas de cálculo.

## Estructura del Directorio

- [/manuales/](./manuales/) - Documentación técnica y manuales de usuario de cada módulo (Ventas, CRM, Compras, RPA).
- `/Enunciado/` - Documentación oficial y rúbrica del proyecto.
- `/Distribucion/` - Archivos de organización interna del equipo.

## Tecnologías Utilizadas

- **ERP:** Odoo Community 18
- **Base de Datos:** PostgreSQL
- **RPA:** UiPath
- **Web Analytics:** Google Analytics (GA4)
- **Infraestructura:** AWS / Cloud Platform
